# ហាងរចនាម៉ូតវាំងនន ប៉ោយប៉ែត (Poipet Modern Curtain Store & Admin System)

គម្រោងគេហទំព័រពេញលេញរួមមាន **Website សម្រាប់អតិថិជន** និង **Admin Dashboard សម្រាប់ម្ចាស់ហាង**។

---

## 🌟 រចនាសម្ព័ន្ធនៃប្រព័ន្ធទាំងមូល

### ១. Website សម្រាប់អតិថិជន (`index.html`)
- **មើលម៉ូតវាំងនន និងពណ៌ក្រណាត់៖** ជម្រើសម៉ូត ២ ជាន់, Smart Motor, Roller, Ripple Fold, Vertical Blinds ជាមួយ Color Picker ចុចប្តូរពណ៌ជាក់ស្តែង។
- **មើលតម្លៃ និងប្រូម៉ូសិន៖** តម្លៃគិតជាម៉ែត្រការ៉េ និងកាតាឡុកប្រូម៉ូសិនបញ្ចុះតម្លៃ ២០% និងថែម Smart Hub។
- **គណនាតម្លៃវាំងនន៖** គណនាទំហំ ទទឹង (m) x កម្ពស់ (m) x ចំនួនបង្អួច ចេញតម្លៃប៉ាន់ស្មានភ្លាមៗ។
- **កម្មង់តាមអនឡាញ៖** មានកន្ត្រកទំនិញ (Shopping Cart) និង Checkout Form បញ្ចូលឈ្មោះ លេខទូរស័ព្ទ និងទីតាំងនៅក្រុងប៉ោយប៉ែត។
- **ទាក់ទងតាម Telegram៖** ប៊ូតុងអណ្តែត និងបញ្ជូនព័ត៌មានកុម្ម៉ង់ត្រង់ចូល Telegram របស់ហាង។

### ២. Admin Dashboard សម្រាប់ម្ចាស់ហាង (`admin.html`)
- **Web UI CMS Live Editor (មុខងារកែប្រែ Website ផ្ទាល់):** ម្ចាស់ហាងអាចកែឈ្មោះហាង អក្សររត់លើគេ ចំណងជើង Banner រូបភាពធំ និងប្រូម៉ូសិន រួចចុច Save នោះ Website នឹងផ្លាស់ប្តូរតាមភ្លាមៗលើ Browser!
- **ផ្ទាំងសង្ខេប (Dashboard Overview):** បង្ហាញ KPI ចំណូលសរុប ការកុម្ម៉ង់ អតិថិជន ចំណេញសុទ្ធ និងតារាងក្រាហ្វិកចំណូលប្រចាំសប្តាហ៍។
- **គ្រប់គ្រងការកម្មង់ (Order Management):** បញ្ជីតាមដានដំណាក់កាលការងារ (រង់ចាំវាស់វែង, កំពុងកាត់ដេរ, កំពុងដំឡើង, រួចរាល់) ស្វែងរក និងឆាតផ្ទាល់ទៅកាន់អតិថិជន។
- **គ្រប់គ្រងផលិតផល (Product Management):** កែប្រែតម្លៃលក់ក្នុងមួយម៉ែត្រការ៉េ បន្ថែមពណ៌ក្រណាត់ថ្មី និងបន្ថែមម៉ូតវាំងនន។
- **គ្រប់គ្រងអតិថិជន (Customer CRM):** ប្រវត្តិអតិថិជន លេខទូរស័ព្ទ ទីតាំងផ្ទះនៅប៉ោយប៉ែត ចំនួនដងកុម្ម៉ង់ និងទឹកប្រាក់សរុប។
- **គ្រប់គ្រងបុគ្គលិក (Staff Management):** បញ្ជីជាងដំឡើង ជាងកាត់ដេរ ចំនួនការងារសកម្ម និងពិន្ទុ Rating។
- **របាយការណ៍ចំណូល និងចំណេញ (Financial Reports):** គណនាប្រាក់ចំណេញសុទ្ធ (Net Profit Margin), តារាងប្រៀបធៀបចំណូល vs ចំណេញតាមខែ (Bar Chart) និងចំណែកចំណាយដើមទុន (Expense Breakdown Pie Chart)។
